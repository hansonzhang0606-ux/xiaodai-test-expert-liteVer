# 时间节省追踪 Skill v5.9 更新说明

发布日期：2026-08-31

## 本次增量升级

1. 新增 `ai_estimated_time_saved_hours`，单位为小时，用于保存 AI 对本环节可节省工时的独立预估。
2. AI 预估必须在展示参考范围和收集测试人员反馈前生成，不得写入或替代 `time_saved_hours`。
3. 测试人员回复“采纳”时，取参考范围中间值 `(min_hours + max_hours) / 2`。
4. 最多追问两次仍未提供实际时间时，同样取参考范围中间值，并固定备注“用户未反馈，采用参考中间值”；该分支不再等待第三次确认。
5. 本地 JSONL 始终保留 AI 预估字段；旧调用未传值时记录为 `null`。
6. MySQL 表存在新列时同步 AI 预估；尚未升级时继续按 v5.8 字段同步并给出警告，AI 预估保留在本地，升级后可重新同步补写。
7. 提供 `sql/upgrade_v5.8_to_v5.9.sql`，必须由管理员审核后手动执行，Skill 不自动修改数据库结构。

## 保持不变

- 步骤 `01/02/04/06/07` 的编码、名称和参考范围不变。
- 人天换算、身份校验、业务线隔离、本地记录路径、定时任务和幂等 `record_key` 不变。
- 当前 HTML/CSV 报告继续以 `time_saved_hours` 为统计口径，不单独展示 AI 预估值。
- v5.8 原目录和原压缩包不受影响。

## 数据库升级

管理员在已经选定的目标数据库连接中执行：

```text
time-tracking-skill/sql/upgrade_v5.8_to_v5.9.sql
```

脚本可重复执行，仅新增：

```sql
ai_estimated_time_saved_hours DECIMAL(10,2) NULL
```

# 三端使用说明

## WorkBuddy

1. 运行 `python scripts/build_release.py`。
2. 使用 `dist/xiaodai-testing-expert-lite-v1.0.2-workbuddy.zip` 进入 WorkBuddy 专家包管理流程。
3. 首次会话按提示选择效贷、效融或小贷业务线，在本机配置文件中填写管理员提供的 MySQL 信息，再输入姓名完成校验。

## Codex App

1. 克隆或解压完整仓库并在 Codex 中打开仓库目录。
2. Codex 会从 `.agents/skills/xiaodai-testing-expert-lite/SKILL.md` 发现“效贷测试专家轻量版”。
3. 直接说“开始轻量版测试流程”，或明确指定七个环节中的任意一个。

## Windows VS Code

1. 安装并启用 Codex 扩展。
2. 用 VS Code 打开完整仓库根目录，而不是只打开单个 Skill 子目录。
3. 在 Codex 对话中使用同样的入口和指令。

## 运行环境

- Python 3；首次使用执行 `python -m pip install -r requirements.txt`。其中 Excel 生成依赖 `openpyxl`，配置读取依赖 `PyYAML`，Office/PDF 文档整理依赖 `markitdown[all]`，旧版 Office 文档转换在 Windows 上依赖 `pywin32`。
- 可访问团队 MySQL 的网络环境。
- Windows 计划任务权限；若公司策略禁止注册，时间记录仍保存在本地，可按提示手动同步。
- 输出目录由测试人员指定并在本次会话内复用，不固定到某个盘符。

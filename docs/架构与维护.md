# 架构与维护

## 权威源码

- `skills/ai-testcase-workflow-skill`：轻量业务 Skill v3.7。
- `skills/time-tracking-skill`：时间追踪 Skill v5.9。
- `skills/xiaodai-lite-orchestrator`：融合编排层。

前两个目录来自已确认的发布基线。轻量业务 Skill 保持逐文件一致；时间追踪 Skill 的流程、字段、计算和入库脚本逻辑保持 v5.9 不变，但仓库发行副本将内网主机名、开发库名等环境默认值替换为安全占位值。使用者本机按提示生成配置。外部原始目录不做修改。

融合和安全入口只写在第三个目录。姓名校验及工时写入必须通过 `secure_record_time_saved.py`，计划任务必须通过 `register_sync_tasks.py`；两者分别提供失败关闭的白名单校验和稳定的 Windows Python 路径解析。

## 生成副本

`xiaodai-testing-expert-lite/skills` 和 `plugins/xiaodai-testing-expert-lite/skills` 由 `scripts/build_release.py` 生成。更新任意权威 Skill 后重新构建，不直接修改副本。

## 版本

整合专家版本记录于根 `VERSION`，并同步到 WorkBuddy `plugin.json`、Agent 和 README。业务 Skill 与时间追踪 Skill 保留各自版本号，只有其自身逻辑发生变化时才单独升级。

## 发布前检查

运行 `python scripts/validate_release.py`。它会执行仓库契约测试、时间追踪回归测试、Python 编译检查和敏感文件扫描。
